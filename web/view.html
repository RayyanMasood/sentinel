What does health mean?

Health asks whether the model is getting anywhere on the state it is on. At 1.00 it is. Health falls toward 0 when the model goes round in circles: the check keeps failing the same way while its calls repeat earlier ones or change nothing.

Sentinel works it out from the last 8 tool calls in the state.

  • A call moves the work forward when it reads something new, edits a file into a version not seen before in this state, or runs the check and gets a pass or a new error.
  • A call makes no progress when it reads the same thing again, puts a file back to an earlier version, runs the check and gets the same error, or is a fifth read in a row while the check fails. An edit also loses its credit when the next check fails the same way.
  • The check sets how far health can fall. While the check passes, health is 1.00. Before it has run, or after a new error, health stays at 0.50 or above. Only when the same error keeps coming back does it fall to roughly the share of recent calls that helped.
